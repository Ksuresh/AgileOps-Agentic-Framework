How to label (2 minutes to read)

Each case is an operational situation in a software service. Imagine you advise the Project Manager who owns the release. For each case:

  1. Read the evidence. Values marked missing or last updated … ago were not current at decision time. A green value in the last column is what an up-to-date check shows; treat it as true.
  2. Tick every action you would accept as reasonable to take now.
  3. Pick the single best action, and say how sure you are.
  4. If you cannot decide from this evidence, tick Cannot decide and add a short note.

Use your own judgement. There are no hidden rules to guess, and the cases are in random order. Your answers save as you go, so you can stop and come back.
