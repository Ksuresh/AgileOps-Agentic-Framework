# Paper evidence map (IEEE Access, manuscript Access-2026-46118, revision 5)

Every claim of the paper, the study and protocol behind it, where the data are, and the command that recomputes it.
All commands run from the repository root on the committed data, with no cluster, model or API key
(`pip install -r requirements.txt`; see [`REPRODUCE_REVISION_STUDIES.md`](REPRODUCE_REVISION_STUDIES.md)). Each output
file is committed, so `git status` after a run should be clean. Numbers in the paper are not typed by hand: they are
LaTeX macros in `paper_tables/numbers.tex`, generated by `python -m outcome_study.paper_tables` from the JSON outputs below.

"Pre-specified" means the hypothesis and analysis script were committed before the data (see each `PROTOCOL.md` and
Supplementary Appendix A). "Post hoc" analyses were written after the data and are labelled as such in the paper.
